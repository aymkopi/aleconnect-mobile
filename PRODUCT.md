# Product

## Register

product

## Users

ALECO consumers using a mobile app on Android and iOS to view account information, submit service complaints, check hotlines, and track report status while away from staff tools.

## Product Purpose

Aleconnect Mobile gives consumers a direct service channel for reporting outages, power quality issues, meter concerns, service drop problems, pole hazards, referrals, and other account-related issues. Success means consumers can file a clear report quickly and receive a reference number they can track.

## Brand Personality

Reliable, direct, calm. The interface should feel like a utility service app: clear, official, and task-first.

## Anti-references

Not a marketing landing page, not a heavy staff dashboard, not an exact clone of any reference screenshot, and not decorative UI that slows down reporting.

## Design Principles

- Put report creation and status visibility first.
- Use clear category colors only where they improve scanning.
- Keep forms step-based so consumers do not face one long page.
- Prefer familiar mobile controls, readable labels, and obvious next actions.
- Treat map and attachment features as progressive tools, not required blockers.

## Accessibility & Inclusion

Use readable contrast, large tap targets, descriptive labels, reduced-motion-safe transitions, and plain language for consumers filing reports under stress.
