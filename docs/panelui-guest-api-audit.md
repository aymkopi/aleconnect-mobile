## Implemented guest journeys

Guest Account now reuses the signed-in Account layout with visible, sign-in-restricted private rows. Its identity is Guest, linked details are hidden, and public support/legal destinations remain accessible. Explore services keeps nine quick services and adds the Figma report-history, support, account/preferences and official-link groups.

One globally owned, auto-sized PanelUI BottomSheet shows **Log in to use this feature** with context-specific reports/account/targeted-update copy, **Sign in** and **Keep browsing**. Reports tab is intercepted before navigation. Private shortcuts, notifications and pinning open the same sheet; cold private links return to public Home and preserve a safe sign-in destination. Account and public service previews remain accessible. Public updates use the existing no-bearer public endpoints and isolated public cache; private APIs still decide authorization. Labelled guest sample data is available only in explicitly compiled preview builds, separately from private visual-fixture permissions.

Shared Card/Button/Sheet/Dialog/Select/Search/Toast/Tab/Switch surfaces are flat. Semantic border/input colors are softened in light and dark mode. Tailwind's default border width is 0.75px, covering full and directional default borders without replacing focus or selection outlines. Search's transparent Android stacking elevation is retained because it controls ordering and casts no decorative card shadow. Floating navigation retains its existing 0.5px outline. [Tailwind border utility documentation](https://tailwindcss.com/docs/border-width) and installed compiler behavior were checked.
