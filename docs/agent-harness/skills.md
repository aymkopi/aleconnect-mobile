# Consumer Mobile skill routing

Handle routine copy, styling and established screen changes directly from AGENTS and nearby source. Skills are capabilities selected for the affected task, not a required workflow sequence.

| Skill | Use when |
| --- | --- |
| aleconnect-mobile-workflow | Consumer offline-state, native capability, SDK upgrade or release work |
| aleconnect-cross-project-change | Staff/consumer API, authentication, notification or media contracts change |

Inspect authoritative Staff handlers and affected consumer readers for contract changes. Read only relevant release/native references. App builds and device acceptance remain separate. Installed global plugins retain their own settings; this repo does not reconfigure them.

See [the harness map](index.md) for checks and [evaluation](evaluation.md) for task-level comparison.
